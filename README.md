# Koda Email Assets

Image hosting for the Koda CrossFit Iron View newsletter, served by GitHub Pages.

## Folders
- `shared/` logos, icons, and images reused every month
- `YYYY-MM/` images for that month's newsletter (e.g. `2026-11/`)

## URL format
https://ndyer28.github.io/koda-email-assets/2026-11/veterans-day-wod.jpg

## Rules
- Lowercase filenames, hyphens instead of spaces
- Images exported around 1200px wide (shown at 600px), under 300KB
- Never rename or delete an image used in a sent email, or that email breaks
